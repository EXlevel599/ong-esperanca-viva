ONG Esperança Viva

Site institucional desenvolvido para a ONG Esperança Viva como projeto acadêmico.

Sobre o projeto

O projeto apresenta informações institucionais, projetos sociais, oportunidades de participação e um formulário de cadastro.

Tecnologias utilizadas

HTML5

CSS3

JavaScript Vanilla

Git e GitHub

GitHub Pages

Estrutura

index.html — página inicial

projetos.html — projetos da ONG

cadastro.html — formulário de cadastro

style.css — estilos e responsividade

script.js — interações e funcionalidades

imagens/ — recursos visuais

Acessibilidade

O projeto utiliza elementos semânticos HTML5, associação entre labels e campos de formulário, atributos ARIA, estados de foco e navegação por teclado.

Publicação

O projeto está hospedado no GitHub Pages.

Projeto acadêmico da disciplina de Sistemas de Informação.
